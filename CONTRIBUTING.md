# Contributing

Suggestions, corrections and template improvements are welcome.

1. Describe the problem and intended user.
2. Never submit client data, credentials, proprietary documents or personal information.
3. Label all invented examples and calculations.
4. Provide sources for external factual claims.
5. Prefer small, practical improvements.

**Licensing:** This repository currently has no open-source license. Before accepting substantial external contributions, licensing and contribution rights must be agreed separately.
